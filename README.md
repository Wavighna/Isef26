# Isef26

A basic Next.js website starter.

## Getting Started

Install dependencies:

```bash
npm install
```

If `npm` is not available on your computer, use the local Node/npm install in
this project:

```bash
.tools/node/bin/npm install
```

Run the development server:

```bash
npm run dev
```

Or, with the local Node/npm install:

```bash
.tools/node/bin/npm run dev
```

You can also run the included helper:

```bash
./run-local.sh
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
