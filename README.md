# Isef26

A static Next.js website prototype for the ISEF26 solar overlay concept.

This project uses:

- Next.js App Router
- Tailwind CSS through PostCSS
- Turbopack for local development and production builds
- Hardcoded client-side data only; no API routes or server data fetching

## Getting Started

Use Node.js 20.9 or newer.

Install dependencies:

```bash
npm install
```

If `npm` is not available on your computer, use the local Node/npm install in
this project:

```bash
.tools/node/bin/npm install
```

Run the development server:

```bash
npm run dev
```

Or, with the local Node/npm install:

```bash
.tools/node/bin/npm run dev
```

You can also run the included helper:

```bash
./run-local.sh
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
